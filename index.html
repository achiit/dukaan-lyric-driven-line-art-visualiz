Export to MP4, Android, troubleshooting

This page is a live preview, not an MP4.

Easiest: load song and lyrics, tap Clean view, Fullscreen, start the screen recorder (Android: Quick Settings → Screen record, device audio on Android 14+), then Play.

Automatic (PC, Python + Node + ffmpeg): python make_video.py song.mp3 --language hi --land transcribes the lyrics, finds the mood, and renders a new MP4 per song. Many songs: python make_video.py *.mp3.

Troubleshooting: choppy on Android: switch off glow and amplitude bars, close other tabs. No sound: tap Play once. Wrong pictures: edit the lyrics or add keywords, scenes follow the words. Out of sync: change the start point or nudge.
